# ร่างอีเมลขอข้อมูล ยังไม่ได้ส่ง

ถึง: zone6@oae.go.th

เรื่อง: ขอความอนุเคราะห์ข้อมูลทุเรียนรายอำเภอจังหวัดจันทบุรี พ.ศ. 2557–2568 เพื่อการวิจัย

เรียน ผู้อำนวยการสำนักงานเศรษฐกิจการเกษตรที่ 6

ข้าพเจ้า [ชื่ออาจารย์/ผู้ส่ง] สังกัด [สถาบัน/ภาควิชา] อยู่ระหว่างเตรียมงานวิจัย [ชื่อเรื่องที่เห็นชอบ] เกี่ยวกับความสัมพันธ์ระหว่างดิน อุณหภูมิ และผลผลิตทุเรียนในจังหวัดจันทบุรี จึงขอความอนุเคราะห์ข้อมูลระดับอำเภอ–ปีของทั้ง 10 อำเภอ ช่วง พ.ศ. 2557–2568 เท่าที่มีจริง ได้แก่ ผลผลิตรวม (ตัน) พื้นที่ให้ผล (ไร่) ผลผลิตต่อไร่ (กก./ไร่) และพื้นที่ยืนต้น (ไร่)

ขอข้อมูลพร้อมรหัสอำเภอ นิยามปี หน่วย วิธีสำรวจหรือประมาณค่า สถานะ Forecast/Estimate/Preliminary/Final/Revised วันที่เผยแพร่ วันปรับปรุง และรุ่นข้อมูล หากมีหลายรุ่นขอให้แยกไว้ หากสะดวกขอไฟล์ CSV/XLSX หรือรูปแบบที่หน่วยงานให้ได้ พร้อมเงื่อนไขการใช้วิจัย การอ้างอิง และการตีพิมพ์หรือเผยแพร่ข้อมูลที่ประมวลผลต่อ

โครงการพบตารางปี 2566–2567 ที่อ้าง สศท.6 ในเอกสารกรมส่งเสริมการเกษตร แต่ยังไม่ทราบสถานะและนิยามปี จึงขอแหล่งต้นฉบับและขอคำแนะนำความต่างพื้นที่ยืนต้นขลุงระหว่าง PDF กับ Catalog รวมถึงการจัดแถว/นิยามท่าใหม่ปี 2557–2558 ตามรายละเอียดในเอกสารแนบ โดยยังไม่สรุปว่าข้อมูลแหล่งใดคลาดเคลื่อน

หากบางปีหรืออำเภอไม่มีข้อมูล ขอแจ้งความครบถ้วนตามจริง ไม่จำเป็นต้องประมาณเพิ่ม หากข้อมูลอยู่กับหน่วยงานอื่น ขอความกรุณาแนะนำช่องทางที่เหมาะสม โครงการจะตรวจสอบสิทธิ์ให้ชัดเจนก่อนเผยแพร่

ขอขอบพระคุณสำหรับความอนุเคราะห์

[ชื่อผู้ส่ง / ตำแหน่ง / สถาบัน]

[อีเมลสถาบันและโทรศัพท์ที่อนุญาตให้ใช้]

เอกสารแนบที่เสนอ: ขอบเขตข้อมูลและความครบถ้วนที่ต้องการ 1 หน้า (หน้าที่ 2 ของร่างหนังสือ; บันทึกเป็น PDF เฉพาะหน้านี้หลังอาจารย์ตรวจ)
