# เตรียม GitHub เป็น portfolio

อัปเดต 1 ตุลาคม 2569: เพิ่ม README หน้าแรกให้คนดูเข้าใจงานและวิธีรัน โดยยังไม่เปลี่ยน repository เป็น Public

## ชื่อและคำอธิบาย

ใช้ชื่อเดิม `durian-orchard-data-platform` ได้ ครอบคลุมงาน IoT ข้อมูล แผนที่ และการทดลองโมเดล

ข้อความสำหรับช่อง About:

> IoT-based durian orchard data platform for sensor data collection, data cleaning, soil and weather analysis, interactive visualization, and baseline machine learning experiments.

README ไม่ได้ตั้งค่า About ใน GitHub ให้โดยอัตโนมัติ ให้เจ้าของ repo ใส่ข้อความผ่านหน้า GitHub เมื่อพร้อม

## ก่อนเปิด Public

- [ ] ตรวจไฟล์ที่ tracked และทุก commit ในประวัติ ไม่ใช่ตรวจเฉพาะ staged changes
- [ ] ตรวจ Wi-Fi password, Tuya keys, API tokens, service-role keys และ URL ที่มี credentials
- [ ] ตรวจ output ใน notebook, JSON snapshots, เอกสารและภาพหน้าจอ ซึ่งอาจมีค่าลับหรือข้อมูลส่วนบุคคล
- [ ] ตรวจพิกัดสวน หมายเลขอุปกรณ์ ข้อมูลเจ้าของสวน และข้อมูลบุคคลก่อนเผยแพร่
- [ ] หากคีย์เคยอยู่ในประวัติ Git ให้ revoke/rotate ก่อน การลบไฟล์หรือเพิ่ม .gitignore ไม่เพียงพอ
- [ ] ตรวจสิทธิ์แจกจ่ายข้อมูลของแต่ละแหล่ง การอ้าง URL ไม่ใช่ใบอนุญาตแจกจ่าย
- [ ] ตัดสินใจ license สำหรับโค้ดของตนเอง โดยไม่ครอบสิทธิ์ข้อมูลหรือโค้ดของผู้อื่น
- [ ] ทดลอง clone ในโฟลเดอร์ใหม่และรันตาม README เพื่อแยกสิ่งที่อยู่ใน Git ออกจาก cache ในเครื่อง
- [ ] เพิ่มภาพหน้าจอ dashboard ที่ตรวจแล้วว่าไม่มีข้อมูลส่วนตัว พร้อมระบุว่าเป็นผลจริงหรือภาพตัวอย่าง

`tools/audit_staged_secrets.py` ตรวจเฉพาะค่าลับที่รู้จักในไฟล์ staged ไม่ใช่การรับรองความปลอดภัยทั้ง repo หรือประวัติทั้งหมด

## การเล่าโครงงานในเรซูเม่และสัมภาษณ์

แยกให้ชัดว่าเป็นงานในวิชาเรียน งานที่ทำเอง งานที่ใช้เครื่องมือช่วย และงานที่ทำร่วมกับเพื่อน อธิบาย data pipeline ปัญหา gateway ค่าค้าง การเลือก outdoor readings และข้อจำกัดของข้อมูลระดับจังหวัดได้

นำผลทดลองที่เพิ่มอากาศแล้วยังไม่ดีขึ้นมาเล่าได้ เป็นหลักฐานว่ามีการประเมินจริง ไม่ควรเปลี่ยนเป็นคำอ้างว่าโมเดลพิสูจน์สาเหตุผลผลิตลดหรือวินิจฉัยสุขภาพต้นได้

## สิ่งที่เอกสารรอบนี้ไม่ได้ทำ

ไม่ได้เปลี่ยนชื่อ repo, เปลี่ยน visibility, push, ลบข้อมูลสวน, เปลี่ยน credentials หรือแก้ประวัติ Git ต้องตรวจและอนุมัติการเผยแพร่แยกจากการจัดหน้า portfolio
