# คู่มือโปรเจกต์ แยกตามงาน

เริ่มที่ [หน้าเริ่มต้น](../00_START_HERE_TH.md) แล้วเลือกหมวดที่ต้องใช้ ไม่ต้องอ่านทุกเอกสารหรือรันทุกสคริปต์

- [ติดตั้งและเริ่มเรียน — setup](setup/README_TH.md): ใช้งานบน Mac, ลำดับเรียน Python และ Git/GitHub
- [สวนจริงและเซนเซอร์ — orchard](orchard/README_TH.md): ความหมายค่าที่วัด การติดตั้ง การคลีน และโมเดลเซนเซอร์
- [วิจัยและผลทดลอง — research](research/README_TH.md): แยกโมเดลผลผลิตจังหวัด ออกจากงานดิน/GIS/รายอำเภอ
- [ใช้งานและส่งต่องาน — operations](operations/README_TH.md): สถานะที่บันทึกไว้ คำแนะนำอาจารย์ และการส่งต่อ/เผยแพร่
- [หน้าตาแดชบอร์ด — design](design/README_TH.md): แนวทางภาพลักษณ์และแบบหน้าจอ
- [ประวัติงาน — archive](archive/README_TH.md): Checkpoint, QA และภาพรวมรุ่นเก่า
- [บันทึกการเปลี่ยนแปลง — updates](updates/README_TH.md): สิ่งที่เพิ่มหรือแก้แบบอ่านเป็นเอกสาร พร้อม Excel GAP snapshot ที่รวมใน branch ตามบันทึก 25 ตุลาคม 2569

อ่านผลงานล่าสุดที่ [ดัชนีงานวิจัยภายใน](../research_data/internal_research/README_TH.md) ส่วนการเปิดแผนที่และคำสั่งประจำวันอยู่ใน [คู่มือขั้นตอนละเอียด](setup/WORKFLOW_DETAIL_TH.md)

รายงานอ้างอิง 6 ไฟล์ยังอยู่ชั้น `docs/` เดิม เพราะสคริปต์วิจัยใช้ตรวจหลักฐานจากเส้นทางและ SHA256 เดิม เปิดผ่าน [หมวดงานเชิงพื้นที่](research/spatial/README_TH.md) ได้ ไม่ต้องหาไฟล์เอง โฟลเดอร์ `phase11d_20261012_v1/` และข้อมูลวิจัยที่ล็อกรุ่นยังเก็บไว้ตามเดิม

เอกสารทดลองและ Checkpoint บันทึกสถานะ ณ วันที่ระบุ จึงอาจมีเส้นทางหรือคำสั่งจากโครงสร้างเก่า ใช้ดัชนีหมวดด้านบนเพื่อหาไฟล์ปัจจุบัน
