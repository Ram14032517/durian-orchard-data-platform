# จุดบันทึกงานแผนที่ดินกับทุเรียน 17 ก.ย. 2569

## งานที่ผู้ใช้ขอ

ให้เปิดเห็นผลจริง เปรียบเทียบได้ และแสดงแหล่งอ้างอิง/ความเป็นข้อมูลจริง ก่อนทำทั่วประเทศ ทดลองหนึ่งจังหวัดคือจันทบุรี

## เสร็จแล้ว

- ดาวน์โหลดดินและการใช้ที่ดินจันทบุรีจากกรมพัฒนาที่ดิน เก็บต้นฉบับพร้อม SHA-256 และ SOURCE.md
- ตรวจพบดินปีผลิต 2561 ส่วนไฟล์การใช้ที่ดินปี 2568 ไม่ใช่ข้อมูลปีเดียวกัน
- ทำ spatial intersection ด้วยความละเอียดต้นฉบับ แยก A403 ตรงตัวกับรหัสปลูกผสม มีผลตรวจพื้นที่ซ้อน/ขาดหาย
- เปิดรายงาน offline ที่ `C:\project\research_data\soil_evidence_chanthaburi\START_HERE.html`
- มีสองแผนที่ ตารางสมบัติดิน กราฟพื้นที่ ลิงก์ทางการ และข้อจำกัด ไม่ใส่ค่าจำลอง
- ตรวจในเบราว์เซอร์แล้ว แผนที่แสดงจริง เลือก Tg ทุ่งหว้าแล้วแผนที่/ตาราง/ข้อความเปลี่ยนตาม
- สคริปต์และวิธีรันอยู่ `tools/build_soil_evidence.py`, `tools/soil_evidence_report.html` และ README_TH.md ในโฟลเดอร์ผลลัพธ์
- ตัวเลข A403 539,971.8 ไร่ จาก 8,512 รูปแปลง ไม่ใช่จำนวนสวน ซ้อนดินได้ 99.998% มี 8.2 ไร่ที่ไม่ซ้อน
- ข้อมูลต้นฉบับและผลแผนที่ถูก ignore จาก Git เพราะขนาด/เงื่อนไข NC-ND ยังไม่ publish/push
- ชีตและเซนเซอร์ไม่ได้แก้ในงานนี้ ไม่แตะ repo อื่น ไม่ล็อกอิน ไม่ใช้ reset credit

## การตรวจ

รัน `tools/test_soil_evidence.py` เพื่อตรวจ 5 กลุ่ม: hash, จำนวนจาก DBF ต้นฉบับ, ผลรวมพื้นที่, ตรวจรายรูปแปลง, รายงาน offline พร้อม citations

ภาพในเบราว์เซอร์ตรวจที่ desktop viewport แล้ว ยังไม่ได้ตรวจมือถือหรือเทียบผลด้วย QGIS อิสระ

## ต้องทำต่อก่อนวิจัยตีพิมพ์

1. ตรวจพื้นที่ที่รูปทรงต้องซ่อมและผลต่างก่อน/หลังซ่อม (ดิน 1 / การใช้ที่ดิน 71 รายการ)
2. ตรวจ A403 ที่ซ้อนหน่วยน้ำ W 290.6 ไร่, ชื่อ Rg-Pto และข้อความ pH ผิดในต้นทาง ไม่แก้โดยเดา
3. ยืนยันปี/วันสำรวจจริงของ land-use และเงื่อนไขเผยแพร่ผลดัดแปลงกับเจ้าของข้อมูล
4. ขยายจังหวัดอื่นด้วยการตรวจ schema/CRS/ปีทุกไฟล์ ไม่ hard-code ว่าทุกจังหวัดปีเดียวกัน
5. เชื่อมอากาศ/ผลผลิตอย่างระวังเวลาและระดับพื้นที่ ยังห้ามสรุปว่าดินใดทำให้ผลผลิตสูงกว่า
