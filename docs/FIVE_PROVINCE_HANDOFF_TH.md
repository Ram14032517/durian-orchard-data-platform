# สถานะงาน 26 กันยายน 2569

ขอบเขตล่าสุด: เน้นพื้นที่และฤดูเก็บเกี่ยวของจันทบุรี ชุมพร ศรีสะเกษ อุตรดิตถ์ สุราษฎร์ธานี แสดงเปรียบเทียบรายเดือนแยกปี โดยไม่ถือว่าระยะพืชของทุกอำเภอตรงกัน

หน้าหลักล่าสุด: `research_data/five_province_history/SEASONS_MAP.html`

ไฟล์ประกอบที่เก็บไว้สำหรับต่อยอด:

- `HISTORY.html`: อากาศรายวัน ผลผลิต ชุดดิน และเครื่องมือนับย้อนแบบสมมติ
- `UNIFIED_MAP.html`: ต้นแบบรวมดินและอากาศตามจุด ใช้ `tools/serve_orchard_analysis.py` ที่พอร์ต 8871; ยังไม่ได้ทดสอบหน้าจอและ API แบบ end-to-end
- `HISTORY_ANALYSIS.ipynb`: รันทุกเซลล์ผ่านแล้ว พร้อม HTML สำหรับอ่าน แต่ยังไม่ได้ตรวจภาพหน้าจอเวอร์ชันล่าสุด
- `soil_layers/` ในโฟลเดอร์ priority_provinces: ขอบเขตดิน 5 จังหวัดพร้อมคุณสมบัติและจุดภายใน polygon สำหรับแสดงผล

ตรวจข้อมูลแล้ว: อากาศ 83,520 แถวรวมวันปลายช่วงที่ค่าขาด ผลผลิต 145 จังหวัด–ปี รายเดือน 748 แถว การดาวน์โหลด NASA 25 ชุดสำเร็จและเก็บ URL/hash ไว้แล้ว อากาศล่าสุดที่มีค่าจริง 22 ก.ย. 2569 แสง 20 ก.ย. 2569

จุดอ้างอิงอำเภอ 68 จุดมาจาก polygon ดินชิ้นใหญ่สุดที่มีชื่ออำเภอนั้น ไม่ใช่สวนทุเรียนที่ยืนยันแล้ว ไม่ใช้แทนค่าเฉลี่ยอำเภอ ไม่ได้สร้างค่าผลผลิตรายชุดดิน/อำเภอจากยอดจังหวัด

หน้าหลักฤดูกาลใช้ผลผลิตรายเดือน สศก. ยังไม่มีวันออกดอก ผลอ่อน หรือวันร่วงรายสวนครบทุกปี ข้อมูลระยะจริงและความเสียหายต้องเก็บหลักฐานระดับพื้นที่เพิ่ม

การตรวจที่ยังเหลือ: เปิด SEASONS_MAP.html ทดสอบเลือกจังหวัดและปี ตรวจการแสดงผลบนหน้าจอ และสอบทานรายงานเหตุการณ์ก่อนใช้สรุปเชิงสาเหตุ ไฟล์ข้อมูลดินดิบขนาดใหญ่และงานส่วนอื่นที่ stage ค้างไว้ไม่รวมใน commit งานนี้
