- `tools/analyze_annual_yield_windows.py` ทดลองย้อนหลังสะสม 1–6 เดือนกับผลผลิตต่อไร่ **รายปี** 145 จังหวัด–ปี ไม่มีการทำซ้ำ target เป็นรายเดือน
