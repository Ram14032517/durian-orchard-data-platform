## ผลงานรอบนี้

- `tools/analyze_annual_yield_windows.py` ทดลองย้อนหลังสะสม 1–6 เดือนกับผลผลิตต่อไร่ **รายปี** 145 จังหวัด–ปี ไม่มีการทำซ้ำ target เป็นรายเดือน
- ตัวหารคือพื้นที่ให้ผล ผลผลิตตันแปลงเป็นกิโลกรัม ก่อนหารไร่; แยกฝึกถึง 2021 (125 แถว), validation 2022–2023 (10), test 2024–2025 (10)
- เดือนอ้างอิงตรึงจากเดือนยอดผลผลิตรวมสูงสุดในข้อมูลฝึก ไม่ใช้ปีทดสอบเลือกเดือน: 22=5, 33=6, 53=7, 84=8, 86=8 ไม่ใช่ระยะหรือวันเก็บจริง
- ทุก window ใช้ชุดแถวเดียวกัน อากาศครบรายวันทั้ง 4 ตัวแปร ค่าเฉลี่ยถ่วงวัน ฝนรวมทุกวัน ไม่มีข้อมูลเดือนอ้างอิงหรือเดือนหลังรวมใน feature
- โมเดล ridge ฐานจังหวัด+แนวโน้มปี เทียบเพิ่ม 4 ตัวแปรอากาศ; alpha และ window เลือกด้วย validation เท่านั้น
- validation เลือก 6 เดือน: test MAE 211.95 กก./ไร่ เทียบฐาน 182.55 กก./ไร่ **ยังไม่ดีกว่าฐานบน test** ห้ามเลือก window ใหม่จาก test แล้วอ้างเป็นผลทดสอบอิสระ
- CSV ผลและข้อมูลฝึกอยู่ใน `research_data/five_province_history/training/annual_yield_windows_*`; มี hash แหล่งข้อมูลใน info.json
