# รายงานรายเดือนและชุดเตรียมเทรน — 27 กันยายน 2569

## สิ่งที่เพิ่ม

- `UNIFIED_MAP.html` เลือกจังหวัด ปี และปุ่ม 12 เดือน แยกปฏิทินอ้างอิง อากาศ/ผลผลิต รายงานมีวันกำกับ และตารางเทียบ 5 จังหวัด เครื่องมือเดิมยังอยู่ในส่วนพับขยาย
- ปฏิทินหมอนทองในฤดูจากกรมวิชาการเกษตร ตาราง 1 หน้า 5 อ่านจาก PDF และตรวจภาพตาราง กรอบภาคใต้หลายระยะทับซ้อนตามต้นฉบับ ไม่ตีความเป็นระยะจริงของต้นเดียว
- ทะเบียนตัวอย่าง 6 เหตุการณ์/กำหนดวัน มี URL วันเหตุ และวันเผยแพร่แยกกัน ยังไม่มีรายงานครบทุกเดือน/ทุกอำเภอ
- `tools/read_monthly_report.py` อ่าน CSV และหลักฐานเดียวกันได้โดยตรง ใช้ Python standard library ไม่ต้องเปิดเว็บ
- ชุด `training/` มี panel 2,745 แถว ผ่านเงื่อนไข baseline เบื้องต้น 748 แถว: train 602, validation 71, test 75; ZIP 1.66 MB โดยประมาณพร้อมสำเนาข้อมูลประกอบ
- ไม่รวมเซนเซอร์สวนหรือช่วงค่า gateway ค้าง ไม่สร้าง label สุขภาพต้น และไม่ได้ฝึกโมเดล

## ตรวจแล้ว

- automated tests 17 tests ผ่าน (API 7, ปฏิทิน/ข่าว 5, training join/lag/split/missing 5)
- รัน Python รายงานสุราษฎร์ฯ ก.ค. 2568 สำเร็จ อุณหภูมิ 26.81 °C ฝน 123.25 มม. ผลผลิต 33,905 ตัน ตรงกับหน้ารายงานที่ปัดอุณหภูมิเป็น 26.8
- browser เปลี่ยนครบ 5 จังหวัด หัวข้อเปลี่ยนตรงกัน ตรวจข่าวลับแล ก.พ. 2568 แล้วเปลี่ยนปี 2567 ไม่แสดงข่าวปีเดิม
- สุราษฎร์ฯ มิ.ย. 2569 แสดงกำหนดเก็บ 20 มิ.ย. ซึ่งข่าวเผยแพร่ 26 พ.ค.; เลือก พ.ค. ไม่เอากำหนดเดือน มิ.ย. มาใส่
- ต.ค. 2569 ไม่มีอากาศ/ผลผลิต แสดงไม่มีข้อมูล ไม่แปลงเป็นศูนย์
- ไม่พบ console error ในการทดสอบรอบนี้ ปุ่มเดือนใช้งานด้วย Enter ได้ ทดสอบจอแคบเห็นปุ่มเดือน 3 คอลัมน์; screenshot จอกว้างผ่านเครื่องมือมีสเกลไม่ตรง viewport จึงไม่ถือเป็นการยืนยันภาพจอกว้างครบทุกส่วน (ตรวจ DOM ไม่มี horizontal overflow แล้ว)
- SEASONS_MAP เดิมไม่เปลี่ยนจากการเพิ่ม payload ของรายงานใหม่

## วิธีรันและส่งต่อ

จาก C:\project:

```powershell
python tools/read_monthly_report.py --province 84 --year 2025 --month 7
python tools/prepare_monthly_training.py
python -m unittest discover -s tests -v
```

สร้าง HTML ใช้ pandas และ shapely: `python tools/build_unified_orchard_map.py`

แผนที่: `python tools/serve_orchard_analysis.py` แล้วเปิด http://127.0.0.1:8871/research_data/five_province_history/UNIFIED_MAP.html

HTML ใน tools/ เป็นแม่แบบ ยังมี `__DATA__` จึงเปิดตรงแล้วไม่แสดงข้อมูล ไม่ใช่ไฟล์ผลลัพธ์

## งานที่ยังเหลือ

ตรวจ coverage RH/แสงรายวันก่อนรับรองชุดฝึกจริง ตรวจ latency ของแหล่งข้อมูลสำหรับ backtest ขยายทะเบียนรายงานพร้อมวันจริง และยืนยันพิกัดสวน/วันดอกบานก่อนวิเคราะห์ผลอ่อน ห้าม join ดินระดับจังหวัดแล้วทำซ้ำผลผลิตจังหวัดลงทุกชุดดิน ข้อมูลและคำแนะนำในชุดนี้ยังไม่รองรับการตัดสินใจให้น้ำรายต้น

PDF เต็ม ภาพตรวจ และ weather cache เก็บในเครื่อง ไม่รวม commit นี้; ZIP สร้างซ้ำได้ด้วยสคริปต์และเก็บในเครื่อง ไม่รวม Git เพื่อเลี่ยงข้อมูลซ้ำ ไม่มีการลบต้นฉบับหรือ Google Sheets
