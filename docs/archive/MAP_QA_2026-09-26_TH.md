# ผลทดสอบแผนที่และ API — 26 กันยายน 2569

## ทำแล้วในรอบนี้

- เพิ่มตารางฤดูเก็บเกี่ยวทั้ง 5 จังหวัด เลือกปีและคลิกจังหวัดได้ใน UNIFIED_MAP หน้าเดียว
- เพิ่มปุ่มกลับภาพรวมประเทศไทย
- แก้แผนที่ sticky ทับปุ่มเมื่อหน้าจอแคบ (พบจริงระหว่างทดสอบปัก B) ให้แผนที่เลื่อนตามหน้าบนจอแคบ
- cache อากาศช่วงสิ้นสุดภายใน 31 วันล่าสุดหมดอายุทุก 6 ชั่วโมง; ช่วงเก่าทุก 30 วัน พร้อมตรวจ SHA256
- API เติมวันขาดหายเป็น null ไม่เติมศูนย์ และส่งจำนวนวันที่มีค่าของแต่ละตัวแปรกับ metadata แหล่งที่มา
- เซิร์ฟเวอร์ 8871 เปิดเฉพาะแฟ้มสาธารณะในโฟลเดอร์วิเคราะห์ที่กำหนด ปิด directory listing และการเข้าถึง .git/.secrets/source code

## ผลทดสอบอัตโนมัติ

```powershell
python -m unittest discover -s tests -p test_orchard_api.py
```

ผ่าน 7 tests: null/วันหาย/ฝนศูนย์, cache TTL และ hash, public page 200, private paths/traversal 404, invalid request 400, API สำเร็จพร้อม coverage และ cache hit, upstream timeout 502

ทดสอบ API ใช้ mock และ temporary cache ไม่แก้ raw data จริง ส่วนการทดสอบ live ด้านล่างใช้ต้นทาง NASA จริง

## ผลทดสอบผ่าน browser จริง

- หน้ารวมโหลดและแสดงตาราง 5 จังหวัด ปี 2568; เปลี่ยนเป็น 2567 แล้วตารางเปลี่ยน
- เลือกอำเภอบ้านนาสาร ปัก B แล้วเลือกจันทบุรี จุด A เป็นอำเภอขลุง ชื่อ/พิกัด A และ B แสดงแยกกัน
- ดึง NASA 1–3 เมษายน 2024 สำเร็จ: A อุณหภูมิเฉลี่ย 28.3 °C, B 30.2 °C (ค่าปัดเศษในหน้าจอ) มีอุณหภูมิ A ครบ 3/3 วัน
- เปลี่ยนเดือนเป็นพฤษภาคม 2024: ตารางอากาศถูกล้างและแสดงข้อความให้โหลดใหม่ ไม่แสดงผลเมษายนเป็นผลพฤษภาคม
- ตรวจพบและแก้ปุ่มถูก map ทับใน viewport แคบ แล้วปัก B ได้สำเร็จ

พิกัดเป็นจุดอ้างอิงจากดินในอำเภอ ไม่ใช่สวนยืนยัน; การเทียบครั้งนี้ไม่ใช่หลักฐานผลต่อสุขภาพทุเรียนหรือเหตุผลผลผลิตลด

## ยังไม่ผ่านการตรวจครบ

- คลิก polygon ทุกชุดดิน/ครบ 5 จังหวัด, ย้อนประวัติ URL, การทดสอบ keyboard และหลายขนาดหน้าจออย่างเป็นระบบ
- ทดสอบ request race โดยจงใจเปลี่ยนวันที่ขณะ upstream ตอบช้า
- เพิ่ม coverage/เวลาที่ดึง/ลิงก์ต้นทางที่ API ส่งให้แสดงบน UI รายตัวแปร
- ปรับสรุประยะฤดูในช่วงหลายเดือน (ตอนนี้ข้อความส่วนที่ 3 อ้างเดือนวันสิ้นสุดช่วง)
- สอบทานข่าวเหตุการณ์เดิมและรวบรวม phenology_events พร้อมวันที่เกิดจริง/วันเผยแพร่/ชนิดหลักฐาน
- อัปเดตลิงก์หน้าเก่า 8870 ให้ชี้หน้ารวมใหม่อย่างชัดเจน
