# คลีนค่าอากาศค้าง

ผู้ใช้ยืนยันว่ามีการถอดปลั๊กเกตเวย์รับค่าอากาศ แต่ไม่ได้ระบุเวลาเริ่ม/สิ้นสุดแต่ละเหตุการณ์ จึงใช้กฎตรวจจากข้อมูลเพื่อประมาณช่วงที่ต้องตัดค่าอากาศ

คำสั่ง: ใช้ Python ที่ทำงานได้ตาม LEARNING_PATH_TH.md รัน `tools/clean_stale_weather.py data/export_2026-09-13/readings_15min.csv data/processed/weather_clean_2026-09-13`

กฎ: อุณหภูมิภายนอก ความชื้นภายนอก ความกดอากาศ แสง และ UV ซ้ำพร้อมกันอย่างน้อย 60 นาที แยกตามอุปกรณ์ และตัดช่วงเมื่อข้อมูลห่างเกิน 30 นาทีหรือค่า signature หาย ไม่ใช้ฝนศูนย์หรือแสงศูนย์ตัวเดียวตัดสิน

เปลี่ยนค่าอากาศทั้ง 15 คอลัมน์เป็นค่าว่างในไฟล์ใหม่ เก็บค่าดิน เวลา และจำนวนแถวทั้งหมดไว้ ไม่เติมค่าว่างด้วยศูนย์ ไฟล์ต้นฉบับและชีตไม่เปลี่ยน

วิธีนี้ใช้ข้อมูลย้อนหลังเพื่อระบุทั้งช่วง รวมจุดแรกด้วยอย่างระมัดระวัง จุดแรกอาจยังเป็นค่าจริงและกฎอาจตรวจไม่ครบทุกเหตุการณ์ จึงเก็บธง weather_stale_suspected และรายงานช่วงไว้ตรวจสอบ ไม่ใช้ธงนี้เป็นฟีเจอร์ทำนายแบบเรียลไทม์เพราะอาศัยข้อมูลในอนาคต

ผลตรวจ: 4,593 แถวเดิม, 71 ช่วง, 2,082 แถวถูกเว้นค่าอากาศ ตรวจแล้วค่าดิน/เวลา/คอลัมน์อื่นคงเดิม และค่าอากาศนอกช่วงคงเดิม ไม่มีการเทรนโมเดลใหม่ในขั้นนี้

ไฟล์ใหม่: data/processed/weather_clean_2026-09-13/readings_15min_weather_clean.csv และ weather_stale_intervals.csv (เวลา UTC)

ขั้นถัดไป: ใช้ไฟล์คลีนทำกราฟดินและฝน โดยเว้นช่วงฝนที่ไม่ทราบ ตรวจสถิติแสงและฝนเดิมก่อนใช้ต่อ เพราะผลเดิมอาจรวมค่าค้าง ห้ามสรุปฝนศูนย์ว่าฝนไม่ตกในช่วงที่ข้อมูลถูกตัด
