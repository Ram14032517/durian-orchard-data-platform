## โครงสร้าง

- วันนี้: ไม่เกิน 3 เรื่องที่ควรตรวจ แตะเปิดเหตุผล ระยะที่เจ้าของบันทึก ค่าจากเซนเซอร์จริง และ API current แยกกัน
- พยากรณ์ 7 วัน: ภาพรวม 24–72 ชั่วโมง / รายชั่วโมง 24–48 ชั่วโมง / เลือกดูวันจาก 7 วันและตารางรวม
- คำแนะนำดูแลสวน: น้ำ / ดินและธาตุอาหาร / อากาศและโรค / ระยะการผลิต มีข้อมูลที่ใช้ เวลาวัด สิ่งที่ยังไม่ทราบ และอ้างอิง
- ย้อนหลัง: แยกเซนเซอร์กับผลผลิตสวน เปิดโหลดครั้งแรกเมื่อจำเป็นและเก็บร่างฟอร์มเมื่อสลับแท็บ
- ความรู้ / ชุดดิน: ความหมายและขอบเขตใช้ค่าทั้ง 21 ตัวแปร บริบทระยะที่เลือกเพื่ออ่าน ชุดดินทุ่งหว้า และหลักฐานรองรับ

HomeTabs เก็บ panel ที่เคยเปิดไว้โดยซ่อน DOM แทนการถอด component พยากรณ์ใช้ resource ร่วมกับ Today/คำแนะนำ และไม่ fetch ใหม่เพราะเปลี่ยนแท็บอย่างเดียว รอบอัปเดตเดิม 5 นาทีและคำสั่งโหลดใหม่ยังทำงานตามปกติ

## ขอบเขตหลักฐาน

ช่วง pH 5.5–6.5 เป็นคู่มือทั่วไป ไม่ใช่ค่าที่รับรองสำหรับหัววัดหรือคำสั่งใส่ปูน ขอบเขตอุณหภูมิ/RH จากคู่มือไม่ตีความเป็นช่วงเป้าหมายทุกระยะ ฝนรายปีไม่ใช้แทนเกณฑ์ฝนวันนี้ ยังไม่มีช่วง VPD, EC, NPK หรือเปอร์เซ็นต์ความชื้นดินรายระยะที่ยืนยันกับสวนนี้

งานวิจัยปุ๋ยที่นำมาเป็นตัวอย่างอ่านจากบทคัดย่อทางการเท่านั้น เป็นผลแปลงทดลองอื่น ไม่ได้รับรองหัววัดหรือประโยชน์ของระบบเว็บนี้ ไม่มีสูตรปุ๋ย ปริมาณน้ำ คะแนนเสี่ยงโรค หรือการวินิจฉัยอัตโนมัติ

รายการแหล่งอ้างอิงและข้อจำกัดอยู่ใน MY_ORCHARD_KNOWLEDGE_SOURCES.json

## ชุดดินและภาพ

พิกัดเจ้าของเก็บส่วนตัวเดิม ตรวจ point-in-polygon กับ soil_layers/84.geojson ที่มีอยู่ พบหนึ่งหน่วย Tg ไม่มีการทำ Overlay หรือแก้ Geometry จุดอ้างอิงไม่ยืนยันขอบเขตสวนทั้งหมดหรือดินทุกจุด แผนที่แสดงผลลดรายละเอียด 50 เมตร มาตราส่วนต้นฉบับ 1:25,000 ปีผลิต 2561

บัตรชุดดิน LDD หน้า 1 บรรยายดินตัวแทน Tg ต่างจากดินคล้ายหน้าอื่น ภาพที่แนบเป็นหน้าตัดดินตัวแทนของ LDD ไม่ใช่ภาพถ่ายสวนจริง ส่วนคำอธิบาย pH ในแผนที่กับบัตรดินแสดงแยกกัน ไม่แก้ค่าหัววัดให้ตรงบัตร

ภาพฝังในโมดูล soilTgImage.js เพื่ออ่านภายในโดยไม่เรียกบริการภาพภายนอก ยังไม่ยืนยันใบอนุญาตเผยแพร่ภาพต่อ ต้องตรวจสิทธิ์ก่อนนำงานใหม่นี้ขึ้นภายนอก คง Public HOLD

## ปรับตารางพยากรณ์ 7 วัน (1 พ.ย. 2569)

เพิ่ม SevenDayForecast.jsx: Desktop เปรียบเทียบครบ 7 วันคู่กับรายละเอียดวันเลือก มือถือปัดวันและเปิดตารางรวมได้ ไม่มี dropdown ที่กินพื้นที่กว้างแต่แสดงเพียงวันเดียว

มีคำแนะนำตรวจสวนอัตโนมัติจากสถานะ fresh/cached และค่าฝนของวันที่เลือก ค่าฝนหาย/ติดลบหรือวันผ่านไปไม่ใช้วางแผน ข้อมูลเซนเซอร์เก่า/ผิดปกติเตือนตรวจอุปกรณ์ ระยะมีผลใช้เฉพาะบันทึกสวนตรงกันและไม่เกิน 30 วัน (กติกาความสด ไม่ใช่เกณฑ์ชีววิทยา) ไม่มีเกณฑ์โรคหรือสั่งเปิดน้ำ/ใส่ปุ๋ย

ฝนรวมแสดงเฉพาะครบ 7 วันต่อเนื่องและค่าครบทุกวัน Zero คงเป็น Zero, Missing ไม่เติม Zero วันที่ซ้ำ/ผิดปฏิทินปิดการสรุป แท่งฝนเป็นสัดส่วนเปรียบเทียบในชุดเดียวกัน ไม่ใช่ระดับอันตราย

Focused React tests ล่าสุดผ่าน 26 รายการ ตรวจ UI จริง Desktop/Mobile เลือกวันและตารางครบ 7 วันได้ ไม่พบหน้าล้นแนวนอน ไม่ Deploy/Push ข้อมูลต้นทางและ Protected 101 ไฟล์คงเดิม หลักฐาน .build/forecast-week-qa/
