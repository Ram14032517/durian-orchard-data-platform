## การรวมส่วนที่ชนกัน

- หน้า React เริ่มเป็นภาษาอังกฤษตามความต้องการเดิม เคารพภาษาที่เคยบันทึกไว้ และเลือก TH/EN ได้โดยรักษาค่าฟอร์มและค่าที่ส่ง API
- คงปุ่ม `Mode: Light/Dark` แบบคลิกเดียว การจำธีม และการรองรับ reduced motion ทั้ง React, Classic และหน้าเข้าสู่ระบบ
- ใช้กราฟและแผงเครื่องมือแผนที่จาก main ร่วมกับตัวช่วยการซูม/ย้ายแผนที่ของ branch เดิม คงการยกเลิกการเคลื่อนที่และการปรับขนาดแผนที่หลังย่อเมนู
- คงหน้าที่เคยเปิดไว้เพื่อรักษาฟอร์ม พร้อมการโหลดข้อมูลอ้างอิงเมื่อจำเป็น ไม่คืนตัวจับเวลา GAP ที่ทำให้ React render ซ้ำทุก 1.5 วินาที
- หน้าผลผลิตแสดงปี ค.ศ. ในภาษาอังกฤษ และ พ.ศ. ในภาษาไทย ค่า `year_ce` ในข้อมูล/API/CSV ไม่เปลี่ยน
- รวมคำแปลใหม่ เก็บการป้องกัน implicit option values และข้อความหลักฐานต้นฉบับ แปลเฉพาะ DOM ที่ Leaflet/GAP เป็นเจ้าของ
- Build ทั้ง JavaScript และ Tailwind ใหม่จาก source ที่รวมแล้ว เก็บ bundle ภาษาอังกฤษสำหรับ Classic/login และ URL JavaScript ที่ผูกกับ content hash ให้ตรงกันทั้งเครื่องมือ build สองตัว

- JavaScript: **128 ผ่าน ไม่มี failure หรือ skip**
- Python ทั้งชุด: พบ 547 กรณี ผ่านจริง 485 และข้าม 62 กรณี ไม่มี failure/error; runner รายงาน 496 tests run กับ 15 skip records เพราะ 51 กรณีอยู่ใน 4 คลาสที่ข้ามตั้งแต่ setup และอีก 11 กรณีข้ามรายเมธอด
- กรณีที่ข้ามต้องใช้ optional private/archived research fixtures, workbook OAE ต้นฉบับ หรือ isolated PostgreSQL ที่ไม่ได้ตั้งไว้ ไม่ถือว่าผ่านหรือรับรองระบบจริง
- หลัง build ฉบับสุดท้าย ตรวจ cloud/auth/API อีก 30 กรณี และแพ็กเกจ Vercel อีก 3 กรณี ผ่านทั้งหมด
