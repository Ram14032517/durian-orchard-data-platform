# บันทึกการเปลี่ยนแปลงโปรเจกต์

เอกสารแต่ละฉบับบันทึกว่าเพิ่มหรือแก้อะไร เหตุผล ผลกระทบ สิ่งที่คงเดิม และสิ่งที่ยังไม่ได้ทำ อ่านได้โดยไม่ต้องดู Git diff แต่ไม่แทนประวัติ commit หรือการสำรองโปรเจกต์

- [1 พฤศจิกายน 2569 ฉบับเปิดอ่านใน Safari](PROJECT_UPDATE_2026-11-01_TH.html)
- [1 พฤศจิกายน 2569 แก้ตัวตรวจ input snapshot ข้าม Mac/Windows (รอบแรก)](SNAPSHOT_HASH_FIX_2026-11-01_TH.md)
- [25 ตุลาคม 2569 เพิ่ม Excel GAP และชุดข้อมูลที่ตรวจแล้วเข้า Git](GAP_PUBLICATION_2026-10-25_TH.md)
- [Excel GAP ห้าจังหวัด snapshot 20 ตุลาคม 2026](attachments/GAP_5_PROVINCES_20261020.xlsx)

- [22 ตุลาคม 2569 ฉบับเปิดอ่านใน Safari](PROJECT_UPDATE_2026-10-22_TH.html)

ตั้งแต่ 25 ตุลาคม 2569 ตามคำขอเจ้าของโปรเจกต์ Excel snapshot ที่ระบุข้างบนรวมอยู่ใน Git บน branch `codex/organize-project` แล้ว จึงติดมาด้วยเมื่อ clone/switch มาที่ branch นี้ ไม่ต้องส่ง Excel แยก ไฟล์คงเดิมทุกไบต์และมี hash ใน manifest ส่วนเอกสารแนบอื่นและข้อมูลดิบที่ยังไม่ผ่านการตรวจยังถูก ignore ตามเดิม การเผยแพร่ Git ไม่เปลี่ยนเส้นทางดาวน์โหลดของ local/cloud dashboard และไม่ใช่การ deploy เว็บ

รอบถัดไปให้สร้างเอกสารชื่อวันที่ใหม่ และเพิ่มลิงก์ที่หน้านี้ ไม่เขียนทับข้อสรุปของรอบก่อน แยกหัวข้อที่ทำแล้ว อนุรักษ์ไว้ ตรวจแล้ว และยังรอข้อมูลให้ชัด โดยเฉพาะอย่าเขียนว่า train แล้วหรือเชื่อม IoT สดแล้วหากยังไม่มีหลักฐาน

ไฟล์ Markdown เป็นต้นฉบับ ส่วน HTML เป็นฉบับสร้างเพื่ออ่าน ใช้ environment ของโปรเจกต์รัน `python tools/build_project_update.py` เพื่อสร้างฉบับวันที่ 22 ตุลาคมนี้ใหม่ และ `python tools/build_project_update.py --check` เพื่อตรวจว่าฉบับอ่านตรงกับต้นฉบับและ Excel ที่แนบยังตรงกับไฟล์เดิม เปิด Markdown ใน VS Code แล้วกด Command Shift V เพื่ออ่าน หรือดับเบิลคลิก HTML ใน Finder เพื่อเปิดด้วยเบราว์เซอร์
