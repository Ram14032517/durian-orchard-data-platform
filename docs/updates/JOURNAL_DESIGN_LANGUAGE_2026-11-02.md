# ปรับสัดส่วนและภาษาในสมุดสวน

ใช้ Anthropic Frontend Design, UI/UX Pro Max, Emil Design Engineering และ Mobile Native ตามหน้าที่ คงเมนูหลัก ระบบยืนยันตัวตน API และฐานข้อมูลเดิม ไม่เพิ่ม Library หรือเปลี่ยนข้อมูลผู้ใช้

## ทิศทาง

สมุดสวนใช้ปฏิทินเป็นจุดเริ่มงาน: เลือกวัน → ดูรายการ → เพิ่ม/แก้ไข โทนเดิมเขียว #087457, ฟ้า #e5f2fb สำหรับน้ำ, ทราย #f3eadc สำหรับปุ๋ย, อำพัน #fff0d2 สำหรับการตรวจ ส่วน Dark ใช้พื้นเดิมและสีคู่ที่อ่านได้ คงฟอนต์เดิม ไม่เพิ่มภาพหรือเอฟเฟกต์ประดับ

| Before | After | Why |
|---|---|---|
| ปฏิทินและรายการเต็มความกว้างต่อกัน | จอใหญ่ปฏิทินซ้าย–รายการขวา มือถือหนึ่งคอลัมน์ | ลดพื้นที่ว่างและการเลื่อน |
| ข้อความประกอบยาวแสดงตลอด | รายละเอียดรองอยู่ในส่วนขยาย | ให้เห็นงานหลักก่อน |
| เดือนจาก native picker อาจขึ้นภาษา OS | เลือกเดือน/ปีตามภาษาแอป วันในสัปดาห์ผ่าน Intl | TH แสดง พ.ศ.; EN แสดง ค.ศ. โดยค่าที่ส่ง API ยังเป็น ค.ศ. |
| คำระบบใหม่บางส่วนไม่มีคำแปล | เติมพจนานุกรม: สมุดสวน, ข้อผิดพลาด, ข้อมูลอัปเดต, คำอธิบายตัววัด | ลดข้อความปนภาษา |
| รายการว่างมีเพียงข้อความ | ข้อความและปุ่มเพิ่มกิจกรรมที่วันที่เลือก | รู้ขั้นตอนถัดไป |
| ปุ่มรีเฟรชยาวทำหัวข้อแตกแถวบนมือถือ | ไอคอนพร้อม aria-label/tooltip บนมือถือ ข้อความบนจอใหญ่ | ประหยัดพื้นที่โดยยังใช้คีย์บอร์ด/เครื่องอ่านจอได้ |

## ภาษาและข้อมูล

`web/i18n/en.json` เพิ่มคำแปลใหม่และคำอธิบายวิธีอ่านค่าจาก `measurementDetails.js` โดยไม่เพิ่มเกณฑ์เกษตร เปลี่ยนการแสดงผลเท่านั้น ไม่มีการส่งข้อความออกไปบริการแปลภายนอก

`OrchardJournal.jsx` ใช้ locale สำหรับเดือน/วัน/ปี และคำแปลชื่อกิจกรรมที่ระบบใส่ให้ใหม่ ฟอร์มที่ผู้ใช้พิมพ์เองยังคงเดิมเมื่อสลับภาษา `id`, `orchard_code`, `kind`, `status`, วันที่ และหน่วยที่ส่ง API ไม่แปลค่า enum ปริมาณไม่เปลี่ยน

ชื่อสวน หัวข้อ และหมายเหตุที่บันทึกแล้วทำเครื่องหมาย `data-source-original` เพื่อไม่แปลทับข้อความผู้ใช้ ชื่อภูมิศาสตร์จากทะเบียน GAP คงการสะกดต้นฉบับเมื่อไม่มีชื่ออังกฤษที่ตรวจสอบได้ จึงอาจเห็นชื่อสถานที่ภาษาไทยบนหน้าแผนที่ในโหมด EN ไม่ถือเป็นการแปลข้อความควบคุมระบบ

`Home.jsx` ย่อหัวข้อเมื่อเปิด Journal และเก็บคำอธิบายการอัปเดตในส่วนขยาย ฟอร์มระยะที่ระบบสร้างหัวข้อใหม่ใช้ภาษาที่เลือกเช่นเดียวกัน

`style.css` ปรับสมุดสวนแบบ scoped, min-height ปุ่มและช่องกรอกที่ใช้งานด้วยนิ้ว, ขนาด input 16px บนมือถือป้องกัน iOS zoom, สถานะ focus, Light/Dark และ reduced motion ใช้ memo เก็บชื่อเดือน/วัน ไม่สร้าง Intl formatters หลายตัวใหม่ทุกครั้งที่พิมพ์

## ทดสอบ

- Unit/API ที่เกี่ยวข้อง: React/language 37, activities 8, cloud 26 รวม 71 ข้อ
- Browser ตรวจ EN ทั้งหกแท็บใน Home และหน้าหลัก ผลผลิต/ฤดูกาล/อากาศ ไม่พบอักษรไทยในข้อความระบบที่มองเห็นตามสถานะที่ตรวจ หน้าแผนที่เหลือชื่ออำเภอจากข้อมูลต้นฉบับ ไม่แต่งคำทับศัพท์ รายงาน QA ปิดรหัสทะเบียนก่อนบันทึก
- สมุดสวน EN รวมแบบฟอร์ม: ไม่พบข้อความระบบไทย; สลับ TH/EN ซ้ำสี่ครั้ง ไม่มี API เพิ่มและค่าที่กรอกยังอยู่
- หัวข้ออัตโนมัติเปลี่ยนตามภาษา ข้อความที่ผู้ใช้พิมพ์เองไม่เปลี่ยน และสถานะที่ส่ง API ยังเป็น `done`/`planned`
- ทดสอบเพิ่ม/แก้ไข/รีเฟรชและระยะจากชุด QA ในหน่วยความจำแยก ไม่เขียนข้อมูลทดลองลงสวนจริง
- 360/390/768/1024/1440px ไม่ล้นแนวนอน ตรวจภาพ Light/Dark จริงจาก browser
- ภาพและผลตรวจใน `.build/i18n_qa/`; source/test scripts ใน `.build/test_journal_language.cjs`, `.build/audit_mixed_language.cjs`

ยังไม่ Deploy/Push/Commit ไม่เปลี่ยน Supabase Schema หรือ ML ไม่ได้ทดสอบมือถือเครื่องจริง ตัวแปลครอบคลุมข้อความระบบที่ตรวจและพจนานุกรมที่เพิ่ม ไม่อ้างว่าแปลเอกสารอ้างอิง รูปภาพเอกสาร หรือข้อความที่ผู้ใช้กรอกทั้งหมด


## ตรวจซ้ำหลังผู้ใช้แจ้งภาษาปนหลายหน้า

- ตรวจรุ่นไฟล์ใน Chrome เทียบกับไฟล์ในเครื่องได้ตรงกัน ณ เวลาตรวจ จึงไม่ยืนยันว่าสาเหตุทั้งหมดคือแคชเก่า
- พบข้อผิดพลาดในตัวแปล DOM ภายนอก: ข้าม input ทั้ง element ทำให้ placeholder และ aria-label ช่องค้นหา GAP ไม่แปล แก้ให้แปลเฉพาะข้อความกำกับ โดยไม่เปลี่ยนค่าที่กรอก
- Build React เปลี่ยนรหัส URL JavaScript ตาม SHA-256 อัตโนมัติหลัง Build รวมคำแปลแล้ว ป้องกันการลืมอัปเดต URL สำหรับ immutable cache ไม่บังคับรีโหลดแท็บที่ผู้ใช้กรอกข้อมูลค้างไว้
- Tests ที่เกี่ยวข้อง 40 ผ่าน รวมการกลับภาษาไทย การรักษาค่าที่กรอก การครอบคลุมข้อความ literal ใน React และรหัสไฟล์ Build
- ตรวจด้วย Chrome ใหม่ทั้ง 5 หน้าหลักและ 6 แท็บหน้า Home; เปิดส่วนรายละเอียด และสลับคำอธิบายค่าทั้ง 21 ตัว: ไม่พบข้อความระบบไทยค้างในสถานะ EN ที่ตรวจ ไม่มี pageerror
- ตรวจ placeholder/aria-label/title ที่แสดงในหน้าแผนที่หลังแก้ ไม่พบภาษาไทยค้าง
- ชื่ออำเภอ/ตำบลจากทะเบียนและข้อความที่ผู้ใช้บันทึกยังคงต้นฉบับ ไม่แต่งคำแปลชื่อเฉพาะ ไม่มีการแก้ข้อมูลจริง
- ภาพจริงใน .build/i18n_qa/: weather_en_fixed.png, weather_en_mobile_fixed.png, knowledge_en_fixed.png, yield_en_mobile_fixed.png
- ขอบเขต: การตรวจนี้ไม่รับรองข้อความทุกแบบที่ API อาจส่งกลับในอนาคต และยังไม่ Deploy
