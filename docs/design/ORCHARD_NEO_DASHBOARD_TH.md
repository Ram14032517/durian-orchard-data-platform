# หน้า Neo Dark และประวัติสวน

หน้า “สวนของฉัน” ใช้พื้นที่เต็มสำหรับข้อมูลสวน แยกจากแผนที่ A/B ของงานวิจัย เลือก 24 ชั่วโมง / 7 วัน / 30 วัน และวันที่สิ้นสุดได้ เวลาแสดงเป็น Asia/Bangkok

กราฟ 4 ตัวแปร: ความชื้นดิน อุณหภูมิดิน อุณหภูมิภายนอก และความชื้นอากาศภายนอก จาก sensor_readings ใน Supabase เลือกเฉพาะ ORCHARD_DEVICE_ID ฝั่งเซิร์ฟเวอร์ ไม่ส่ง Secret key ไปเบราว์เซอร์ API /api/orchard-history ต้องล็อกอินบน cloud เช่นเดียวกับ API เดิม

คำนวณค่าเฉลี่ยรายชั่วโมงก่อน แล้วจึงเฉลี่ยรายวันสำหรับ 7/30 วัน ค่าที่อุปกรณ์ระบุ invalid หรืออายุเกิน 1 ชั่วโมงไม่นำมาคำนวณ ช่องว่างแสดง null ไม่ใช่ศูนย์ มีจำนวนตัวอย่างแยกตัวแปรในตาราง ไม่รวม rain_1h_mm ซ้ำเป็นฝนสะสม

อ่านข้อมูลสูงสุด 30,000 ระเบียนต่อคำขอ ถ้าเต็มขีดจำกัดมีป้ายข้อมูลบางส่วน ค่าชั่วโมง/วันแรกและสุดท้ายอาจครอบคลุมไม่เต็มช่วง กราฟนี้เป็นข้อมูลจุดเซนเซอร์ ไม่ใช่ค่าเฉลี่ยทั้งสวน ไม่ใช่ข้อมูลชุดดิน LDD และไม่เปลี่ยนโมเดลผลผลิตจังหวัด

ทดสอบ: tests/test_orchard_history.py, tests/test_orchard_telemetry.js และชุดทดสอบ cloud/map เดิม การผ่าน unit test ไม่ยืนยันว่าคีย์/ตาราง Supabase บน Render เชื่อมได้จริง ต้องตรวจเว็บที่ deploy อีกครั้ง
