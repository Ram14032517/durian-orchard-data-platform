# Field Signal — Visual Brand Direction

สถานะ 10 ต.ค. 2569: นำ Field Signal ไปใช้ในหน้า dashboard แล้ว (ตัวอักษรใช้ fallback ที่มีในเครื่องหากไม่มี Noto Sans Thai / Inter)

หน้าดินรวมแผนที่และแบบเลือก A/B ในส่วนที่ย่อได้ กด “ดูรายละเอียดดิน” เพื่อย่อและอ่านตารางเต็มความกว้าง การสลับหน้าไม่เปิดส่วนที่ย่อไว้เอง กราฟมีปุ่มขยายเต็มจอ และประวัติสวนเลือกวัน/สัปดาห์/เดือนได้

ตรวจ Python 167 รายการ และ JavaScript 18 รายการผ่าน ตรวจการเลือก Tg ในบ้านนาสารเทียบ Bu ในท่าชนะ การย่อ/เปิดกลับ และหน้าจอมือถือ 390px แล้ว การทดสอบหน้าจอใช้เซิร์ฟเวอร์ ไม่เปิด HTML ผ่าน file://; ข้อมูล Supabase บน Render ยังมีข้อผิดพลาดการอ่านที่ต้องแก้ต่างหาก ไม่แสดงข้อมูลจำลองแทน

## จุดยืน

เครื่องมืออ่านสถานการณ์สวนทุเรียนจากเซนเซอร์ อากาศ ดิน และบริบทผลผลิตจังหวัด ให้ข้อมูลชัดก่อนความตกแต่ง เป็นเว็บเกษตรสมัยใหม่ ไม่ใช่เว็บขายสินค้า และไม่อ้างความสามารถเตือนภัยหรือทำนายรายสวนที่ยังไม่ผ่านการสอบเทียบ

บุคลิก: ชัดเจน สงบ แม่นยำ เป็นมิตร ไม่เย็นชาจนเหมือนเครื่องมือสำหรับวิศวกรเท่านั้น

## ทิศทางหลัก: Field Signal

แถบเมนูหมึกเข้ม พื้นที่อ่านข้อมูลสว่าง กราฟเป็นจุดเด่น สีฟ้าและสีเขียวทะเลแยกข้อมูล น้ำหนักตัวอักษรชัด ความเป็นเกษตรมาจากภาพสวนจริงและสัญลักษณ์เส้นเรียบ ไม่มาจากการทาสีเขียวทุกกล่อง

| บทบาท | สี | การใช้ |
|---|---|---|
| Ink | #132D38 | ตัวอักษรหลัก เมนูด้านบน |
| Canvas | #F4F7F7 | พื้นหลังหน้า |
| Surface | #FFFFFF | พื้นอ่านข้อมูล |
| Teal | #087F8C | แบรนด์และข้อมูลน้ำ/ความชื้น |
| Sky | #2563EB | ข้อมูลอากาศและพื้นที่ A |
| Harvest | #B45309 | พื้นที่ B และจุดเน้น โดยไม่สื่อว่าเป็นภัยอัตโนมัติ |
| Secondary text | #40545E | คำอธิบาย แหล่งข้อมูล |
| Danger | #B42318 | ข้อผิดพลาดที่ยืนยันได้ พร้อมข้อความ |

Contrast บนพื้นขาว: Ink 14.38:1, Teal 4.75:1, Sky 5.17:1, Harvest 5.02:1 คำนวณตามสูตร relative luminance ของ sRGB ไม่ใช่ผล audit ทุกสถานะหน้าจอ ต้องตรวจจริงอีกครั้งเมื่อสร้าง component

พื้นที่ส่วนใหญ่เป็นสีกลาง สีแบรนด์ใช้กับการกระทำสำคัญและข้อมูล ไม่ระบายทุกปุ่มด้วยสีเข้ม ใช้ข้อความ/หน่วย/รูปแบบเส้นร่วมกับสีเสมอ

## ตัวอักษรและความหนาแน่น

- ไทย: Noto Sans Thai; ละตินและตัวเลข: Inter; fallback Tahoma, Arial, sans-serif
- เนื้อหา 16–18 px, line-height 1.55–1.65, น้ำหนัก 400
- ป้ายกำกับ 16 px น้ำหนัก 600; หัวส่วน 24 px น้ำหนัก 700
- ตัวเลขหลัก 32–40 px; ใช้ tabular numbers; หน่วยเล็กกว่าค่าแต่ยังอ่านได้
- 14 px ใช้เฉพาะข้อมูลรอง ไม่ใช้กับปุ่มหลักหรือข้อความผิดพลาด
- ระยะห่างฐาน 8 px, มุม 8–12 px, ไม่ซ้อนเส้นกรอบหลายชั้น

## โครงหน้าจอ

Navbar กระชับอยู่นอกพื้นที่เนื้อหาที่เลื่อน: สวน / อากาศ / ดิน / ผลผลิต / แผนที่ ปุ่มดาวน์โหลดเป็นเครื่องมือในหน้าที่เกี่ยวข้อง ไม่จำเป็นต้องแย่งลำดับกับงานหลัก

1. สวน: เวลาวัดล่าสุด แหล่งข้อมูลและความครบถ้วน ตามด้วยกราฟรายวัน/สัปดาห์/เดือน
2. อากาศ: เลือกเวลาและตัวแปรด้านบน กราฟใหญ่เต็มความกว้าง ตารางเปิดเมื่อต้องการ
3. ดิน: การเลือกตำแหน่งแยกจากคุณสมบัติดิน ชื่อชุดดินและปีข้อมูลชัด ไม่แสดงเป็นผลตรวจสวน
4. ผลผลิต: แยกผลผลิตทางการออกจากค่าทำนาย มีปี หน่วย และข้อจำกัดโมเดล
5. แผนที่: แผนที่เต็มพื้นที่ เป้าหมาย A/B ชัด เลือกแล้วกลับหน้าข้อมูลได้

ไม่มีแผนที่บังคับกินครึ่งจอขณะอ่านกราฟหรือเลือกดิน ไม่ย่อข้อมูลทั้งแอปให้พอดีจอด้วยการลดขนาดตัวอักษร ให้เลือกดูงานเดียวและขยายกราฟเฉพาะตัวได้

โทรศัพท์: หน้าข้อมูลเต็มความกว้าง ปุ่มสัมผัสอย่างน้อย 44 px เมนูเข้าถึงได้โดยไม่ต้องเลื่อนเนื้อหาลงล่าง กราฟขยายเต็มพื้นที่ได้ ตารางเลื่อนในกรอบของตาราง ไม่ทำให้ทั้งหน้าเกินขอบ

## ภาพและรูปแบบกราฟ

ภาพสวนจริงใช้เฉพาะหน้าเข้าสู่ระบบหรือบริบทสวน ไม่ทำพื้นหลังกราฟ สัญลักษณ์ใช้เส้นเดียวกัน เช่น หยดน้ำ เมฆ ชั้นดิน และเส้นขอบผลทุเรียน ไม่ใช้ emoji แทนระบบไอคอน

กราฟเส้นมีชื่อ หน่วย ช่วงเวลา แหล่งข้อมูล เส้นกริดบางแต่เห็นได้ และข้อมูลเมื่อชี้/แตะ จุดไม่มีข้อมูลต้องเป็นช่องว่าง ไม่เติมศูนย์หรือเชื่อมเส้นข้าม ปริมาณฝนเหมาะกับกราฟแท่ง; เมื่อหน่วยต่างกันให้แยกกราฟหรือบอกแกนชัด ไม่ซ้อนจนชวนเข้าใจผิด

ไม่มีข้อมูล: บอกเหตุที่ทราบ ปุ่มลองโหลดใหม่ และไม่วาดกราฟเปล่าขนาดใหญ่
ข้อมูลเก่า: แสดงเวลาวัดจริงและอายุข้อมูล
ค่าทำนาย: ป้ายคาดการณ์และช่วงความไม่แน่นอนเมื่อมีหลักฐานรองรับ

## สองทิศทางรอง

Night Observatory: ถ่านอมฟ้า #101C24, พื้นยก #1B2B35, ตัวอักษร #EAF2F5, cyan #5DD6D0 และ amber #F6BD60 เหมาะดูกราฟกลางคืน แต่ต้องตรวจความต่างสีและไม่ใช้ glow รบกวนกราฟ

Orchard Editorial: ivory #FAF7EF, forest ink #193C34, saffron #A65C00 ภาพสวนและข้อความเด่น ให้ความอบอุ่นกว่า แต่มีบุคลิกเครื่องมือข้อมูลน้อยกว่าทิศทางหลัก

ข้อเสนอ: ใช้ Field Signal เป็นค่าเริ่มต้น และพิจารณา Night Observatory เป็นโหมดมืดภายหลัง ไม่รวมทั้งสามสไตล์ปะปนในหน้าเดียว

## เกณฑ์ตรวจเมื่อพัฒนา

- ผู้อ่านมองออกว่ากำลังดูสวนจริงหรือข้อมูลจังหวัด และข้อมูลมาจากเวลาไหน
- เมนูไม่หายเมื่อเลื่อน และหน้าดิน/แผนที่ไม่แบ่งครึ่งโดยบังคับ
- แสดงกราฟเดียวเต็มพื้นที่ได้ และเปลี่ยนวัน/สัปดาห์/เดือนได้โดยไม่หาปุ่มใหม่
- ตัวอักษรหลักมี contrast อย่างน้อย 4.5:1; สีไม่เป็นช่องทางสื่อความหมายเพียงอย่างเดียว
- Loading, empty, error และ stale เป็นคนละสถานะ ไม่แสดงค่าจำลองเป็นข้อมูลสด
- ภาพ visual concept ใช้เพื่อประเมินทิศทาง ไม่ใช่หลักฐานว่า API หรือเว็บทำงานแล้ว
