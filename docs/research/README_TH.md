# วิจัยและผลทดลอง

[กลับดัชนีคู่มือ](../README_TH.md) · [ดัชนีงานวิจัยภายในล่าสุด](../../research_data/internal_research/README_TH.md)

- [โมเดลและข้อมูลย้อนหลัง — modeling](modeling/README_TH.md): Ridge/VPD, การประเมินตามเวลา, ENSO, การขยายจังหวัด และข้อจำกัดการพยากรณ์
- [ดินและพื้นที่ — spatial](spatial/README_TH.md): GIS, ข้อมูลรายอำเภอจันทบุรี, หน่วยดินท่าใหม่ และการขอข้อมูลเพิ่ม

รายงานใน `docs/` อธิบายวิธีและผลทดลอง ส่วน Dataset, Manifest, PDF และหลักฐานแต่ละรุ่นอยู่ใน `research_data/` ตามเดิม การจัดโฟลเดอร์คู่มือครั้งนี้ไม่ได้ฝึกโมเดลหรือสร้างผลทดลองใหม่

ผลผลิตระดับจังหวัด ข้อมูลรายอำเภอ และค่าที่วัดในสวนเป็นคนละหน่วยวิเคราะห์ ตรวจคำนิยามและข้อจำกัดในรายงานก่อนนำมาเทียบกัน
