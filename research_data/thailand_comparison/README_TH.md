## ไฟล์หลัก

1. `THAILAND_MAP.html` — ดับเบิลคลิกเปิดแผนที่ออฟไลน์ เลือกปี/ตัวชี้วัด/ภาค/จังหวัด เทียบ A กับ B
2. `ANALYSIS_NOTEBOOK.html` — อ่านผลตาราง กราฟ วิธีคำนวณ และข้อจำกัด โดยไม่ต้องติดตั้ง Jupyter
3. `../../notebooks/02_thailand_durian_comparison.ipynb` — สมุด Jupyter ที่รันครบด้วย kernel จริงและบันทึกผลแล้ว
4. `province_year_panel.csv` — ตารางเชื่อม 385 แถว (77 จังหวัด × 2021–2025)
5. `production_province_year.csv` — ผลผลิตย้อนหลังทั้งหมด 1997–2025 (1,107 จังหวัด–ปี)
6. `weather_monthly.csv` — อากาศ4ตัวแปร 4,620 จังหวัด–เดือน และพิกัดจุดอ้างอิง

## ค้นพบเบื้องต้น ปี 2568

- ผลรวมจังหวัดที่มีข้อมูล 1,573,851.69 ตัน; ตารางประเทศ สศก. 1,573,852 ตัน ต่าง0.31ตัน ไม่ปรับทับกัน
- ผลผลิตต่อไร่รวมแบบถ่วงเนื้อที่ให้ผลประมาณ1,230กก./ไร่
- ภาคตะวันออกและภาคใต้รวมกัน91.9% ของผลรวมจังหวัดที่มีระเบียน (แบ่งภาคแบบ DPM REGION_6)
- จันทบุรี575,611ตัน ชุมพร278,840ตัน ระยอง188,321ตัน มากที่สุดสามอันดับ
- จันทบุรีผลผลิตต่อไร่ตามต้นทาง1,714กก./ไร่ และชุมพร1,158กก./ไร่
  แต่ตัวเลขนี้ยังไม่บอกว่าดินหรืออากาศเป็นสาเหตุ
- ปี2568เทียบ2567: ผลผลิตรวม+22.2%, เนื้อที่ให้ผล+12.1%, ผลผลิตต่อไร่+9.0%
  จึงไม่ควรอธิบายปริมาณผลผลิตที่เพิ่มขึ้นด้วยอุณหภูมิเพียงตัวเดียว
- จำนวนจังหวัดที่มีระเบียนปี2021–2025 = 49,59,59,67,67 ตามลำดับ
  การปรากฏในฐานข้อมูลครั้งแรกไม่ได้พิสูจน์ว่าเพิ่งเริ่มปลูก และปีที่ไม่มีแถวไม่ถูกเติมเป็นศูนย์

## ตรงโจทย์อาจารย์ถึงไหน

| งาน | สถานะ |
|---|---|
| หาและเก็บผลผลิตย้อนหลังพร้อมที่มา | มีไฟล์จริงระดับจังหวัดและประเทศ |
| เปรียบเทียบประเทศ–ภาค–จังหวัด | มีตาราง กราฟ และแผนที่77จังหวัด |
| อากาศ ฝน ความชื้น แสงย้อนหลัง | มี5ปีที่จุดอ้างอิงจังหวัด ไม่ใช่แปลงทุเรียน |
| ชุดดินใต้พื้นที่ปลูกทุเรียนแต่ละภูมิภาค | จันทบุรีผ่านการซ้อนทับเบื้องต้น; จังหวัดอื่นยังขาด |
| พิกัดแปลงทุเรียนข้ามภูมิภาคสำหรับอากาศ | ยังต้องสกัดจาก land-use A403 แล้วถ่วงพื้นที่/กริด |
| วิเคราะห์อากาศเพิ่ม–ลดแล้วผลผลิตเปลี่ยน | ยังทำไม่ได้อย่างน่าเชื่อถือ ไม่ใส่ผลจำลองปลอม |
| ตีพิมพ์ dataset | ยังต้องเพิ่มพื้นที่/ปี ตรวจสิทธิ์ใช้ และทำ data dictionary/methodology/version |

สิ่งที่อาจารย์เสนอคือสร้างชุดข้อมูลวิจัยที่เชื่อมกันได้ ไม่ใช่โหลดทุกไฟล์โดยไม่มีหน่วยพื้นที่และปีร่วมกัน
แผนที่เป็นเครื่องมือตรวจข้อมูล งานหลักยังเป็นการวิเคราะห์ใน Jupyter

## ขั้นต่อไปเพื่อทำงานตามอาจารย์

1. คัดจังหวัดนำร่องข้ามภาคจากผลผลิตจริง เช่น จันทบุรี ชุมพร ศรีสะเกษ อุตรดิตถ์
   ไม่อ้างว่า4จังหวัดแทนความหลากหลายทั้งหมดของประเทศ
2. ดาวน์โหลด soil series + land-use ของจังหวัดเหล่านั้นจาก LDD ตรวจปี CRS รหัสA403/รหัสผสม
3. สกัดพื้นที่ทุเรียนและหน่วยดินจริง เก็บหลายจุดหรือใช้สัดส่วนพื้นที่ในแต่ละกริดอากาศ
   อย่าเรียกจุดกลางจังหวัดว่าพิกัดสวน และอย่าแจกผลผลิตจังหวัดไปเป็นผลจริงรายชุดดิน
4. ขยายอากาศย้อนหลังให้สอดคล้องปีผลผลิต จัดช่วงก่อนออกดอก/ติดผลตามภูมิภาค
   แยก annual descriptive profile จาก weather exposure ในฤดูที่สัมพันธ์กับผลผลิต
5. ทำ baseline ผลผลิตต่อไร่ “เท่าปีก่อน” → โมเดล regression แบบมีปัจจัยพื้นที่และเวลา
   ทดสอบแบบแยกปีและแยกจังหวัด รายงาน MAE/RMSE และ uncertainty ไม่สุ่มแถวปนอนาคต
6. วิเคราะห์อุณหภูมิ±1°C ภายในช่วงข้อมูลเป็น sensitivity scenario เท่านั้น
   หากต้องการอ้างผลเชิงสาเหตุ ต้องออกแบบปัจจัยกวน/การจัดการ/ความชื้น/ฝนร่วมกับอาจารย์
7. เตรียม dataset card: provenance, license, dictionary, missing/quality flags,
   temporal/spatial resolution, split strategy, version/checksum; ตรวจสิทธิ์ก่อนเผยแพร่
