# แฟ้มข้อมูลสำหรับคุยกับอาจารย์

**แผนที่ตัวอย่างที่เปิดดูได้:** [ดินและพื้นที่ทุเรียนจันทบุรี](soil_evidence_chanthaburi/START_HERE.html) พร้อม [วิธีอ่านและข้อจำกัด](soil_evidence_chanthaburi/README_TH.md) และ [หลักฐานไฟล์ต้นทางกรมพัฒนาที่ดิน](external/ldd_chanthaburi_2026-09-17/SOURCE.md)

**เริ่มที่ [ผลตรวจล่าสุด 17 ก.ย. 2569](00_REVIEW_2026-09-17_TH.md)** มีรายการจุดที่ต้องแก้และข้อมูลที่ควรหาเพิ่ม

ดาวน์โหลดไฟล์จริงจาก สศก. เพิ่มแล้ว: [ผลผลิตรายปี](external/oae_2026-09-17/durian_province.xlsx) และ [ผลผลิตรายเดือน](external/oae_2026-09-17/durian_monthly_province.xlsx) พร้อม [ที่มาและผลตรวจเบื้องต้น](external/oae_2026-09-17/SOURCE.md)

เปิดโฟลเดอร์นี้ใน VS Code หรือ File Explorer ได้เลย ไฟล์ต้นฉบับยังอยู่ใน `data/export_2026-09-13` และ `data/processed` เช่นเดิม

## ไฟล์ที่มีในโฟลเดอร์นี้

| ไฟล์ | ความหมาย |
|---|---|
| `04_farm_sensor_raw.csv` | ข้อมูลจากสวนดิบ 15 นาที ใช้ดูแหล่งข้อมูลและปัญหาค่าอากาศค้าง |
| `05_farm_sensor_weather_clean.csv` | สำเนาคลีนที่เว้นค่าอากาศช่วงค้าง เก็บค่าดินและเวลาไว้ |
| `01_durian_yield_source.txt` | ลิงก์ชุดผลผลิตทุเรียนรายจังหวัด/รายปีจาก OAE |
| `02_soil_source.txt` | ลิงก์ข้อมูลชุดดินจากกรมพัฒนาที่ดิน |
| `03_weather_source.txt` | ลิงก์สถิติอากาศและฝนจากกรมอุตุนิยมวิทยา |
| `data_dictionary_TH.md` | คำอธิบายหน่วยข้อมูลและแผนการเชื่อมข้อมูล |

## สิ่งที่นำเสนออาจารย์

ข้อมูลผลผลิตภายนอกมี XLSX ต้นทางที่ตรวจแล้ว ดินและการใช้ที่ดินดาวน์โหลดและทดลองซ้อนทับจริงแล้วเฉพาะจังหวัดจันทบุรี ส่วนจังหวัดอื่นและอากาศยังต้องเลือกชุดข้อมูล/ปีและตรวจเงื่อนไขการเผยแพร่ งานจะเชื่อมด้วย `จังหวัด + ปี` สำหรับโมเดลผลผลิต และเก็บข้อมูลสวน 15 นาทีเป็นชุดภาคสนามแยกต่างหาก

ไฟล์ CSV มีข้อมูลจริงจากสวน ไม่ควรส่งต่อสาธารณะก่อนตรวจสิทธิ์และลบข้อมูลที่ระบุตำแหน่งละเอียด
