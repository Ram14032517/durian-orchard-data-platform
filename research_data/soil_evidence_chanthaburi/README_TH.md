# เปิดดูแผนที่และหลักฐาน

ดับเบิลคลิก **START_HERE.html** ในโฟลเดอร์นี้ แล้วเลือกเปิดด้วย Edge หรือ Chrome ไม่ต้องติดตั้ง QGIS ไม่ต้องล็อกอิน และเปิดแบบ offline ได้ ข้อมูลและตัวแสดงผลรวมอยู่ในไฟล์แล้ว

## ใช้ตอนคุยกับอาจารย์

1. แผนที่ซ้ายคือดินจันทบุรีทั้งจังหวัด ปีผลิต 2561
2. แผนที่ขวาคือเฉพาะพื้นที่การใช้ที่ดิน A403 (ทุเรียน) ปีไฟล์ 2568 ซ้อนกับแผนที่ดิน
3. เลือก `Tg — ทุ่งหว้า` เพื่อดูตัวอย่างหน่วยดินเดียวกับที่ผู้ใช้บอก แต่ยังไม่ได้ยืนยันว่าเซนเซอร์ของผู้ใช้อยู่ในหน่วยดินนี้
4. ดูตารางสมบัติดินและกราฟเปรียบเทียบพื้นที่ ไม่ใช่กราฟความเหมาะสม/ผลผลิต
5. เลื่อนลงหัวข้อ “ข้อมูลจริงหรือไม่ และมาจากไหน?” มีลิงก์ต้นฉบับ ปีข้อมูล วิธีคำนวณ ข้อจำกัด และ SHA-256

## ผลคำนวณรอบ 17 ก.ย. 2569

- A403 ตรงตัว: 8,512 รูปแปลง พื้นที่เรขาคณิต 539,971.8 ไร่
- รหัสปลูกผสมที่มี A403: 5,364 รูปแปลง พื้นที่รวม 139,426.6 ไร่ ไม่ถือว่าทั้งหมดเป็นทุเรียน
- พื้นที่ A403 ซ้อนแผนที่ดินได้ 539,963.6 ไร่ เหลือไม่ซ้อนทับ 8.2 ไร่
- ทุ่งหว้า Tg: A403 ประมาณ 14,725.3 ไร่ เป็นผลคำนวณของโปรเจกต์ ไม่ใช่ผลสรุปที่กรมฯ รับรอง
- จำนวนรูปแปลงไม่ใช่จำนวนสวน/เกษตรกร/ต้นไม้

## วิธีคำนวณที่ทำซ้ำได้

- ต้นฉบับและแหล่งอ้างอิงอยู่ใน `../external/ldd_chanthaburi_2026-09-17/` และ `SOURCE.md`
- สคริปต์ `../../tools/build_soil_evidence.py` ตรวจ SHA-256 ก่อนเริ่ม ไม่แก้ raw
- อ่านระบบพิกัดจริงจาก .prj ตรวจตรง EPSG:32647 ทั้งคู่
- แยก `LU_CODE == A403` ออกจากรหัสแบบหลายพืช โดยแยกส่วนด้วย `/`
- ซ่อมเรขาคณิตที่ไม่ valid ด้วย Shapely make_valid ในหน่วยความจำ: ดิน 1 record / การใช้ที่ดิน 71 records เก็บเฉพาะส่วน polygon
- ตัดส่วนซ้อนทับที่ความละเอียดเดิม ไม่ใช้ centroid จับคู่และไม่ใช้รูปร่างที่ลดรายละเอียดมาวัดพื้นที่
- คิดพื้นที่ใน projected CRS ตารางเมตร / 1,600 = ไร่ เป็นพื้นที่แผนที่ ไม่ใช่พื้นที่สำรวจรังวัด
- ตรวจพื้นที่ทับซ้อนภายใน A403, ภายในรหัสผสม, ระหว่างสองกลุ่ม และการนับซ้ำจากหน่วยดิน เกณฑ์หยุดถ้าเกิน 0.1 ไร่
- ลดรายละเอียดเส้นเพื่อแสดงภาพเท่านั้น: ดิน/อำเภอ 100 เมตร, ส่วนซ้อนทับทุเรียน 30 เมตร แล้วแปลงเป็น WGS84 longitude/latitude
- ใช้ Python + Shapely 2.1.2 + pyproj 3.8.0 + pyshp 3.1.6; ตัวแสดงแผนที่ D3 7.9.0
- เก็บผลรวม/เวอร์ชัน/ที่มาใน `analysis.json` และผลตรวจรายรูปแปลงใน `polygon_audit.json`

## ข้อจำกัดที่ต้องพูดให้ชัด

- ทดลองเพียงจังหวัดจันทบุรี ยังไม่ครบประเทศ
- ดินปีผลิต 2561 กับการใช้ที่ดินปี 2568 คนละช่วงเวลา ปีชื่อไฟล์ไม่ใช่วันสำรวจรายแปลง
- เจอ A403 ซ้อนหน่วย W (พื้นที่น้ำ) 290.6 ไร่ ควรตรวจตำแหน่ง/การเปลี่ยนแปลง/การจำแนก ไม่เปลี่ยนชื่อหน่วยน้ำเป็นชุดดิน
- รักษาข้อความต้นทาง แม้มีการสะกดผิด ไม่สร้างค่า pH ตัวเลขหรือเกณฑ์ทุเรียนขึ้นเอง
- มีการซ่อมรูปทรง จึงควรตรวจความเปลี่ยนแปลงพื้นที่จากการซ่อม/สอบทานกับ GIS อิสระก่อนตีพิมพ์
- ไม่ระบุพันธุ์หมอนทอง อายุ ระยะพืช สุขภาพ หรือผลผลิตของแต่ละแปลง
- ยังไม่มีการเชื่อมกับอากาศ/ผลผลิต สรุปได้เพียงพื้นที่สำรวจที่ซ้อนกับหน่วยดิน ไม่ใช่ผลเชิงเหตุและผล
- ที่มาจากหน่วยงานจริงไม่รับประกันว่าทุกค่าถูกต้อง ห้ามเรียกว่า ground truth ทุกจุด
- แผนที่ 1:25,000 ไม่ใช่ขอบเขตกรรมสิทธิ์และไม่แทนผลตรวจดินในสวน
- ยังไม่ส่งขึ้น GitHub/เว็บ ต้องตรวจสิทธิ์ NC-ND กับเจ้าของก่อนเผยแพร่ชุดข้อมูลดัดแปลง
